# 1. 리더보드 산식

---

### ■ Stage 1 점수

- **설명**: 재녹화 여부 판별 결과는 원본과 재녹화 클래스의 F1 점수를 동일하게 평균하는 **Macro-F1**으로 평가합니다.

$$Score_{stage1} = \frac{F1_{ORIGINAL} + F1_{RERECORDED}}{2}$$

---

### ■ Stage 2 점수

- **설명**:
  - 참가자는 충돌시점과 진입시점을 **프레임 번호**로 제출합니다.
  - 제출된 프레임 번호를 영상별 프레임-시간 대응정보를 이용하여 초 단위로 변환한 후 정답 시각과 비교합니다.

| 평가항목 | 평가산식 | 가중치 |
| :--- | :--- | :---: |
| 충돌시점 | Accuracy@0.3초 | 0.35 |
| 진입시점 | Accuracy@0.3초 | 0.35 |
| 진입방향 | Macro-F1 | 0.15 |
| 회피 공간 여부 | Macro-F1 | 0.15 |

$$Score_{stage2} = 0.35S_{collision} + 0.35S_{entry} + 0.15S_{direction} + 0.15S_{evasion}$$

> **⚠️ 오답 처리 기준**
> - 예측값 누락
> - 결측값 또는 비수치값
> - 음수 프레임
> - 해당 영상의 범위를 벗어난 프레임
> - 허용된 범주 이외의 분류값

---

### ■ Stage 3 점수

| 평가항목 | 평가산식 | 가중치 |
| :--- | :--- | :---: |
| 가감속 범주 | Macro-F1 | 0.7 |
| 조향 범주 | Macro-F1 | 0.3 |

$$Score_{stage3} = 0.7F1_{accel} + 0.3F1_{steer}$$

> **📌 유의사항**
> - Stage 3 조향 범주 평가는 차량이 주행 중인 유효 프레임을 대상으로 수행하며, 정지 상태(`STOPPED`)로 판정된 프레임은 조향 평가 대상에서 제외됩니다.
> - 다만 참가자는 제출 형식의 일관성을 위해 정지 상태를 포함한 모든 프레임에 대해 `steer_label`을 출력해야 합니다.
> - 정지 상태 프레임의 조향 예측값은 조향 Macro-F1 산정에 반영되지 않습니다.

# 2. 평가 기준

---

### ■ 1차 평가 : Private Score
대회 종료 시점의 Public Score의 종합 점수로 산정됩니다.

- **Stage별 가중치**
  - **Stage 1**: $0.2$
  - **Stage 2**: $0.4$
  - **Stage 3**: $0.4$

---

### ■ 2차 평가 : 종합 평가
- **대상**: 2차 평가 자료를 제출하고 검증을 통과한 **1차 평가 점수 기준 상위 15팀**
