# 공개 예제 데이터 준비

## 원본 보호

- `DOC/` 원본을 수정하거나 직접 실행 산출물을 기록하지 않는다.
- 공개 예제는 명시적인 개발 경로로 복사한 뒤 사용한다.
- 이미 존재하는 개발 데이터를 묵시적으로 덮어쓰지 않는다.

## 구조 검사

- Stage 1 labels의 영상 경로와 분류 레이블을 검사한다.
- Stage 2 labels의 영상 경로와 시점·장면 컬럼을 검사한다.
- Stage 3 labels의 ID별 영상과 표본·프레임 컬럼을 검사한다.
- 선택적으로 각 영상의 첫 프레임이 디코딩되는지 검사한다.

## 증거 제한

- 공개 예제 통과는 실행·입출력 호환 증거로만 사용한다.
- 공개 예제로 측정한 값은 일반화 성능이나 공식 대회 점수로 보고하지 않는다.
